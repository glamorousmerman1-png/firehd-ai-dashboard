# ⚡ Fire HD常駐型「AIインテリジェンス・ダッシュボード」

## 🌟 主な機能

1. **🏃 習慣・健康・ToDo（Habit & Health & Task Tracker - 旧taskkanri統合 / デフォルト画面）**
   - **🏆 月間実績カレンダー & 今月の頑張りサマリー**:
     - **月間カレンダーグリッド**: 日曜〜土曜の7列カレンダーで各日の達成度を色分け表示（8/8パーフェクト👑、高達成✨、部分達成など）。血圧（🩺）、ゴルフ球数（🏌️）、メモ（📝）も各マスにインライン表示
     - **今月の頑張りサマリーカード**: 記録継続日数、日課クリア総数、パーフェクト達成日数、血圧平均値、ゴルフ打球数を集計
     - **前月・翌月の振り返り**: 過去月（8月・7月など）のカレンダーや頑張りサマリーにもワンタップで切り替え可能
   - **🔥 実績を称えてやる気を出す！（AIエール・モチベーション機能）**:
     - ワンクリックで、通算記録日数（145日超）や今月のクリア回数、毎日の血圧測定などの実績データをAIが読み解き、あなたの自己規律を全力で高評価・大絶賛！やる気とエネルギーが湧き上がる熱いエールをお届け
   - **定常日課（全8項目）チェックリスト**: 運動・健康（血圧測定、プランク、スクワット、降圧ストレッチ、パター練習）、記録・管理（AI日記、AI家計簿、株価チェック）を日別管理
   - **血圧数値のインライン記録**: 「血圧測定」にチェックを入れると、最高血圧（上）と最低血圧（下）をmmHg単位で記録・保存
   - **ゴルフ打ちっぱなし実績**: 実施チェック ＆ 打った球数を記録
   - **毎日の備考（メモ）**: 未消化理由やひとことメモを記録
   - **スムーズな日付移動**: 「◀ 前日」「翌日 ▶」「📅 今日に戻る」ボタンと日付指定ピッカーが完全に同期連動し、過去の日付の実績も軽快に閲覧・編集可能
   - **個別タスク（Adhoc Tasks）管理**: 起票日、ステータス（起票/対応中/完了）、期限日、備考の登録・変更・削除
   - **ストリーク（連続達成日数 🔥）& 統計**: 習慣ごとの連続日数、今月日数、累計日数をリアルタイム集計
   - **📥 過去データ移行・インポート & 💾 バックアップ**: 旧アプリ（`taskkanri`）のバックアップJSONやFirestoreデータをそのまま貼り付けるだけで、過去の記録を1件も失わずに完全復元
2. **📊 市況ブリーフィング（Intelligence Briefing）**
   - 「国内・グローバル市況」「AI & テックトレンド」「ビジネストピック」の3カテゴリを最新動向から要約
   - 3行要点要約、注目インサイト、市況感バッジ（ポジティブ/中立/警戒）を3カラム並列カードでひと目で把握
3. **📈 銘柄ニュース・材料（Stock Intelligence）**
   - **Google Web検索グラウンディング連携**: Google検索ツールを活用し、2026年直近の最新ニュース、決算・適時開示、株価材料をリアルタイムに自動リサーチ
   - **3つのカテゴリ対応**:
     - 💼 **保有銘柄 (ポートフォリオ)**: 全30保有銘柄から気になる銘柄を選択して最新動向を要約
     - ⭐ **購入検討銘柄 (ウォッチリスト)**: 注目銘柄の追加・削除管理および動向チェック
     - 🔎 **自由検索 (スポット調査)**: 保有・検討リスト外の企業でも、銘柄コードや社名を入力して即座に最新調査。気になった銘柄はワンクリックでウォッチリストに保存可能
   - **元記事リンク直接アクセス**: AIが参照したニュースや適時開示の元記事リンクを表示
4. **🎯 銘柄発掘・スクリーニング（Stock Discovery & Screening）**
   - **🚀 最近好調・テーマ別発掘**: 半導体AI、高配当バリュー、防衛重工など注目の投資テーマから注目銘柄をAIが厳選提案
   - **🎁 株主優待おすすめ検索**: 権利確定月やジャンルを指定して優待銘柄をリサーチ
   - **📅 今月決算・発表予定銘柄**: 当月や直近に決算発表を控える注目企業をリストアップ
5. **💼 ポートフォリオAI診断・リスク評価（Portfolio Intelligence）**
   - **総資産（日本株＋海外・積立資産）の統合集計**: 日本株個別株（約3,768万円）に加え、米国株式、積立投信、確定拠出年金DC、債券を含めた総資産（約5,100万円超）の資産配分を統合管理
   - **客観的な弱点・リスク診断 & 具体的処方箋**: アセット偏りや特定セクター集中をヘッジする補完銘柄をウォッチリストから提案
6. **💡 思考整理・ブレスト（Brainstorm & Wall-hit）**
   - アイデアや課題を入力すると、Geminiが即座に多角的視点（共感・批判的検証・ネクストアクション）から壁打ち
7. **📝 タスク・アドバイザー（Daily Task Advisor）**
   - **全端末リアルタイム同期（クラウド共通ストレージ）**: 仕事PC、プライベート端末、Fire HDタブレットなど、どの端末からアクセスしても同一のToDoタスクとAIアドバイスを共有・保持
   - タスクの追加・完了チェック・個別削除・完了一括消去が全端末に即時反映
   - 「🔄 最新同期」ボタンで、別端末での最新編集内容をワンタップで即時再読込
   - 「AIアドバイス生成」ボタンで、最優先タスクの選定・時間配分や段取りのコツ・モチベーションメッセージを生成し、全端末で共有表示
8. **🔐 パスワード（合言葉）ロック機能**
   - 不特定多数からのアクセスを防ぎ、自分専用として安全に運用するためのロック画面を搭載
   - クラウドのSecretsにパスワードを設定することで、合言葉を入力したユーザーのみがアクセス可能
9. **🎨 カスタム指示（回答トーン・キャラクター設定）**
   - `custom_instructions.txt` ファイルに好みの口調やスタンス（親しみやすいトーン、専門用語の噛み砕きなど）を記載するだけで、AIの全回答スタイルを自由にカスタマイズ可能

## 📱 Fire HD（Silkブラウザ）での常駐設定のコツ

Fire HD（7 / 8 / 10 等）をスマートディスプレイ化して快適に常駐運用するための設定テクニックです。

### ① 全画面・ツールバー非表示で開く
上記記載の常駐用URL（末尾に `?embed=true` を付けたURL）で開くと、上部のStreamlitヘッダーなどが最小化され、タブレット画面いっぱいに表示されます。
```text
https://ngrwi3j3aajjq2qjkugxsh.streamlit.app/?embed=true
```

### ② ホーム画面にブックマーク（アプリ化）
1. Fire HD標準の **Silkブラウザ** で上記URLを開きます。
2. 画面右上のメニューアイコン（3点リーダー）をタップします。
3. **「ホーム画面に追加」**（または「ページを固定」）を選択します。
4. ホーム画面に専用アイコンが生成され、次回から1タップですぐにダッシュボードを全画面風に起動できます。

### ③ 常駐時の画面スリープ防止（常時オンにする）
デスク脇で時計やダッシュボードとして常時点灯させる場合の設定です：
- **設定アプリ** > **端末オプション** > **シリアル番号** を7回タップして「開発者向けオプション」を有効化します。
- **設定アプリ** > **端末オプション** > **開発者向けオプション** を開き、**「スリープモードにしない（充電中は画面をスリープ状態にしない）」** をONにします。
- 充電スタンドやUSBケーブルを接続しておけば、PCの電源がオフでもFire HD単体で24時間ダッシュボードが表示され続けます。

## 🚀 ローカルPCでのテスト実行手順

```bash
# プロジェクトフォルダに移動
cd "g:\マイドライブ\Antiglavity\.agent\firehd-ai-dashboard"

# 仮想環境の作成 (任意)
python -m venv venv
venv\Scripts\activate

# 依存ライブラリのインストール

# アプリ起動
```
