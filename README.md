## 🌟 主な機能

1. **📊 情報ブリーフィング（Intelligence Briefing）**
   - 「国内・グローバル市況」「AI & テックトレンド」「ビジネストピック」の3カテゴリを最新動向から要約
   - 3行要点要約、注目インサイト、市況感バッジ（ポジティブ/中立/警戒）を3カラム並列カードでひと目で把握
2. **📈 銘柄ニュース・材料（Stock Intelligence）**
   - **Google Web検索グラウンディング連携**: Google検索ツールを活用し、2026年直近の最新ニュース、決算・適時開示、株価材料をリアルタイムに自動リサーチ
   - **3つのカテゴリ対応**:
     - 💼 **保有銘柄 (ポートフォリオ)**: 全30保有銘柄から気になる銘柄を選択して最新動向を要約
     - ⭐ **購入検討銘柄 (ウォッチリスト)**: 注目銘柄の追加・削除管理および動向チェック
     - 🔎 **自由検索 (スポット調査)**: 保有・検討リスト外の企業でも、銘柄コードや社名（例: ソシオネクスト、テスラ等）を入力して即座に最新調査。気になった銘柄はそのままワンクリックでウォッチリストに保存可能
   - **元記事リンク直接アクセス**: 各カード内および下部リストに、AIが参照したニュースや適時開示の元記事リンクを表示。気になる記事をタップしてそのまま閲覧可能
   - 直近ニュース、好材料・リスク要因、プロの投資インサイト、材料バッジを整理してカード形式で表示
3. **🎯 銘柄発掘・スクリーニング（Stock Discovery & Screening）**
   - **🚀 最近好調・テーマ別発掘**: 半導体AI、高配当バリュー、防衛重工、商社、自動車、金融、DXなど注目の投資テーマ（または自由入力）から、直近で好調な理由、カタリスト、おすすめ度（★）、投資リスクを備えた注目銘柄をAIが厳選提案
   - **🎁 株主優待おすすめ検索**: 権利確定月（今月9月、来月10月、3月人気など）やジャンル（飲食食事券、買物割引、QUOカード、カタログギフト等）を指定して、総合利回りや生活に役立つ優待銘柄をリサーチ
   - **📅 今月決算・発表予定銘柄**: 当月や直近に決算発表を控える注目企業をリストアップし、発表予定日、注目着眼点、市場コンセンサス、決算リスクを整理
   - **⭐ ワンクリック・ウォッチリスト連携**: 発掘した魅力的な銘柄をその場でワンクリックでウォッチリストに保存可能（「銘柄ニュース」タブで日々の最新動向を継続ウォッチ）
   - **🌐 Google Web検索連携 & 元記事リンク**: 直近の最新市場データ、IR情報、アナリスト評価を参照し、記事タイトル付きのクリッカブルリンクを提供
4. **💼 ポートフォリオAI診断・リスク評価（Portfolio Intelligence）**
   - **リアルタイム資産集計**: 保有30銘柄の「総資産評価額」「トータル含み損益（円・%）」「年間予想受取配当金」「平均配当利回り」「NISA口座 vs 特定口座比率」をリアルタイム自動算出
   - **客観的な弱点・リスク診断**: 「日本株（東証上場株）が多すぎる」「特定銘柄（三菱重工等）への過大集中」「特定セクター（外食チェーン4社、重工・コングロマリット等）の重なり」など潜在リスクをAIが客観的に浮き彫りに
   - **リスク中和のための具体的処方箋**: 偏りをヘッジ・是正するために今後優先して買い増すべきアセットやセクターを具体的に指南
   - **ウォッチリスト連動レコメンド**: ユーザーが登録している**「購入検討銘柄（ウォッチリスト97銘柄）」の中から、現在のポートフォリオの穴を埋めるのに最適な補完銘柄をAIが厳選提案**
5. **💡 思考整理・ブレスト（Brainstorm & Wall-hit）**
   - アイデアや課題を入力すると、Geminiが即座に多角的視点から壁打ち
   - 「共感・アイデア拡張」「批判的検証（悪魔の代弁者）」「ネクストアクション3選」の3枚のカードで出力
6. **📝 タスク・アドバイザー（Daily Task Advisor）**
   - タスクの追加・完了チェック・個別削除ができる軽量ToDoリスト
   - 「AIアドバイス生成」ボタンで、最優先タスクの選定・時間配分や段取りのコツ・モチベーションメッセージを常時掲示
7. **🔐 パスワード（合言葉）ロック機能**
   - 不特定多数からのアクセスを防ぎ、自分専用として安全に運用するためのロック画面を搭載
   - クラウドのSecretsにパスワードを設定することで、合言葉を入力したユーザーのみがアクセス可能
8. **🎨 カスタム指示（回答トーン・キャラクター設定）**
   - `custom_instructions.txt` ファイルに好みの口調やスタンス（親しみやすいトーン、専門用語の噛み砕きなど）を記載するだけで、AIの全回答スタイルを自由にカスタマイズ可能

## 📱 Fire HD（Silkブラウザ）での常駐設定のコツ

Fire HD（7 / 8 / 10 等）をスマートディスプレイ化して快適に常駐運用するための設定テクニックです。

### ① 全画面・ツールバー非表示で開く
上記記載の常駐用URL（末尾に `?embed=true` を付けたURL）で開くと、上部のStreamlitヘッダーなどが最小化され、タブレット画面いっぱいに表示されます。
```text
https://ngrwi3j3aajjq2qjkugxsh.streamlit.app/?embed=true
```

### ② ホーム画面にブックマーク（アプリ化）
1. Fire HD標準の **Silkブラウザ** で上記URLを開きます。
2. 画面右上のメニューアイコン（3点リーダー）をタップします。
3. **「ホーム画面に追加」**（または「ページを固定」）を選択します。
4. ホーム画面に専用アイコンが生成され、次回から1タップですぐにダッシュボードを全画面風に起動できます。

### ③ 常駐時の画面スリープ防止（常時オンにする）
デスク脇で時計やダッシュボードとして常時点灯させる場合の設定です：
- **設定アプリ** > **端末オプション** > **シリアル番号** を7回タップして「開発者向けオプション」を有効化します。
- **設定アプリ** > **端末オプション** > **開発者向けオプション** を開き、**「スリープモードにしない（充電中は画面をスリープ状態にしない）」** をONにします。
- 充電スタンドやUSBケーブルを接続しておけば、PCの電源がオフでもFire HD単体で24時間ダッシュボードが表示され続けます。

## 🚀 ローカルPCでのテスト実行手順

```bash
# プロジェクトフォルダに移動
cd "g:\マイドライブ\Antiglavity\.agent\firehd-ai-dashboard"

# 仮想環境の作成 (任意)
python -m venv venv
venv\Scripts\activate

# 依存ライブラリのインストール

# アプリ起動
```
